# FG-117 — Dark Zen palette and macOS 27-style rounded UI

## 1. Summary

- Replaced the previous dark theme with the owner-provided Dark Zen semantic
  palette: charcoal-blue backgrounds, slate surfaces, mist text,
  blue-lavender actions, teal/blue/lavender progress, and muted semantic
  states.
- Centralized 10, 14, 20, 28, and pill corner radii and applied them to
  buttons, fields, numeric inputs, selectors, list rows, cards, sections,
  chips, progress tracks, tooltips, flyout presenters, and the strict modal.
- Added restrained action and progress gradients, layered timer halos, quieter
  sidebar selection, 40-pixel controls, and visible focus treatment.
- Preserved all strict-mode consequences, exact expiration text, warning
  content, recovery code workflow, keyboard behavior, and enforcement logic.
- Rebuilt a self-contained Windows x64 graphical installer and complete ZIP.

## 6. UX implications

The visual hierarchy is calmer and softer while preserving the timer as the
dominant element. Important actions retain restrained gradients, ordinary
controls remain quieter, and warnings remain explicit through copy, icons,
borders, and color. Forty-pixel control heights and two-pixel keyboard focus
borders improve practical targeting and focus visibility.

## 7. Security implications

No domain, service, IPC, policy, persistence, recovery, registry, ACL, browser,
or enforcement behavior changed. Danger is still reserved for real errors or
destructive actions. The default theme request remains system-controlled so
this milestone does not explicitly suppress an operating-system accessibility
theme.

## 8. Limitations

- The Windows capture helper failed twice against the Avalonia window with
  `SetIsBorderRequired ... 0x80004002`; the local build did open, but no
  screenshot-based visual sign-off is claimed.
- The first default-package rebuild removed the previous package contents but
  could not remove the now-empty `FocusGuard-0.1.0` directory because Explorer
  held it open. No desktop processes were closed. The complete replacement was
  generated under the `FocusGuard-0.1.0-dark-zen` path.
- The installer was built and inspected but not executed. Reinstallation
  remains owner-present and will request UAC.
- Store-signed Chrome/Edge publication remains the unrelated FG-113 blocker.
