## Summary

Added a dedicated strict-confirmation review screen with explicit end time, impacted scope, browser health, recovery workflow, unsaved-work warning, exact typed confirmation, and simulator-only activation feedback.

- Shows profile, finite exact local end time, impacted applications, impacted website rules, and browser-extension health.
- Explains the recovery-code workflow without generating or storing a code.

## UX implications

The review is a dedicated screen rather than a small modal. Consequences and recovery appear before the confirmation field; the end time is repeated in the primary action for an unambiguous final check.

## Security and recovery implications

This milestone is UI-only. It does not generate, hash, store, reveal, or validate recovery codes and cannot activate strict persistence or enforcement.
