# FG-117 — Dark Zen palette and rounded UI plan

## Goal

Apply the owner-provided Dark Zen palette and a consistent macOS 27-style
rounded geometry to the FocusGuard Desktop UI, then produce reinstallable
installer artifacts.

## Acceptance criteria

- Semantic theme resources use the supplied charcoal, slate, mist, lavender,
  sage, amber, and muted-coral palette.
- Buttons, inputs, selectors, lists, cards, sections, chips, rings, and the
  strict-review modal use centralized rounded-corner tokens.
- Primary actions and timer/progress visuals use the supplied restrained
  gradients.
- Focus indicators remain visible and strict/recovery warnings retain text,
  iconography, border, and semantic contrast.
- Automated tests pin the palette and geometry contracts.
- Formatting, Release build, Desktop tests, installer tests, full relevant
  tests, browser-package checks, and graph update pass.
- A fresh graphical installer and complete ZIP are generated and verified.

## Implementation plan

1. Extend the semantic token dictionary with the Dark Zen colors, action and
   progress gradients, field/list surfaces, shadows, and rounded geometry.
2. Update shared control styles so every relevant control family consumes the
   same tokens, including popup/list item surfaces.
3. Remove remaining hard-coded legacy radii and ring colors from views.
4. Add source-level design-system contract tests.
5. Validate the Desktop and installer, update the graph, rebuild artifacts,
   and record checksums and paths.

## UX implications

The interface will become softer and calmer without changing navigation,
content hierarchy, copy, control targets, keyboard behavior, or the explicit
strict-mode consequences and exact expiration information.

## Security implications

This is a visual-only milestone. No enforcement, IPC, persistence, recovery,
privilege, registry, ACL, service, or browser-policy behavior changes. Warning
and danger states remain visually distinct and never rely on color alone.

## Recovery implications

No recovery workflow behavior changes. The one-time recovery code, delayed
recovery guidance, cancel path, and strict expiration details remain visible.
Reinstallation remains owner-present because the generated setup requests UAC.
