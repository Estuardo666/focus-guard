# FG-121 Local Git Baseline

## 1. Summary

Initialized a local Git repository in the FocusGuard workspace with `main` as
the initial branch. The baseline captures the existing project while excluding
generated output, dependencies, local application state, logs, caches, and
machine-specific configuration.

No product logic, installed service, browser integration, installer, or machine
configuration was changed.

None. This milestone changes repository metadata and documentation only.

## 4. Commands executed

- `git --version`

## 5. Results

- Git version: `2.52.0.windows.1`
- Repository root: the FocusGuard workspace only
- Initial branch: `main`
- Staged baseline before this completion record: 343 files
- Excluded-path violations: 0
- Sensitive-filename matches: 0
- Private-key content matches: 0
- Credential-assignment matches: 0
- Representative local paths were confirmed ignored:
  - `.codex/hooks.json`
  - `extension/node_modules`
  - `artifacts`
  - `desktop-run.log`
  - `graphify-out/cache`
  - `graphify-out/manifest.json`

Git reported expected LF-to-CRLF normalization notices because the repository
editor configuration specifies CRLF for the affected text files. No working
files were rewritten during staging.

No build or automated test suite was run because no application or test code
changed. The previously observed baseline remains: build and automated tests
pass, while formatting verification has existing line-ending and whitespace
failures that must be reconciled as a separate reviewable task.

## 6. UX implications

None.

## 7. Security implications

Runtime databases, logs, tool state, dependency trees, and cache metadata are
not versioned. The staged content scan found no private keys or credential-like
assignments. This is a preventive audit, not a guarantee that arbitrary prose
or historical files contain no sensitive business information.

## 8. Limitations

- The repository is local only; no remote or upstream branch is configured.
- Existing formatting failures are intentionally preserved in the baseline.
- Graphify's durable reports and graph exports remain versioned, while its
  machine-local root marker, manifest, and cache are ignored.
