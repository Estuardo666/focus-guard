# FG-120 — Calm motion and state-painting isolation checkpoint

## 1. Summary

Removed the remaining sidebar/button flashes and grey duration-hover states at
their source. Standard buttons now use a FocusGuard-owned implicit template;
navigation and duration presets keep isolated dedicated themes, so broad
Fluent or application states cannot paint over them. The modal no longer
disables the entire shell while opening or closing.

Applied the owner's calm-motion direction: exact non-linear hover/focus spline
resources, 160 ms hover motion, physical `1.015`/`0.985` button scale,
subtle surface/border/shadow feedback, 260 ms screen entry, 280 ms modal
fade/scale, 180 ms dropdown motion, 120 ms tooltip motion, 180 ms switch-thumb
motion, scale-based checkbox appearance, and a 5.5-second halo-opacity cycle.

## 6. UX implications

Normal sidebar rows are visually free. Hover adds only a 4% white surface,
selected rows keep a transparent background, and the active icon alone carries
the profile accent. Standard controls gain depth through combined small
luminance, border, shadow, and scale changes instead of abrupt grey fills.
Modal opening now materializes from `0.97` scale rather than sliding from a
large offset.

The Apple-design guidance led to restrained, non-overshooting, interruptible
property transitions and symmetric modal paths. No bounce, elastic, rotation,
ripple, RGB glow, or transition over 350 ms was added.

## 7. Security implications

No service, enforcement, IPC, persistence, recovery, browser policy, or strict
expiration behavior changed. Removing `ApplicationShell.IsEnabled` avoids a
visual state cascade only: the modal overlay remains hit-testable, the shell
remains non-hit-testable, keyboard navigation cycles inside the dialog, and
focus returns to its prior element after close.

## 8. Limitations

Computer-use screenshot capture was interrupted because user input was
detected in the test window; the helper correctly stopped controlling it.
Fresh local and packaged process/window/event verification passed, and the
style-priority regressions are automated, but final subjective hover/motion
review remains owner-present after reinstalling.

The halo uses supported opacity keyframes around a static 18 px blur. Avalonia
12 has no registered keyframe animator for `RenderTransform`; geometric looping
scale remains intentionally excluded because it previously prevented the
Desktop from opening.
