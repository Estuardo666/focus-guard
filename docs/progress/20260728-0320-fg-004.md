# FG-004 checkpoint

## Summary

Added URL normalization and wildcard matching with browser-internal fail-open handling and explicit allow precedence.

## Acceptance evidence

- Bare domains, subdomains, path wildcards, and scheme wildcards are tested.
- Query strings and fragments are excluded before evaluation.
- Browser-internal URLs are allowed without applying website rules.
- Explicit allow rules take precedence over matching block rules; otherwise default is allow.
- Release build completed with zero warnings/errors and 18/18 tests passed.

## Security, UX, and recovery implications

The engine is local pure logic and does not inspect unrelated browsing history or communicate with a browser. It intentionally does not install or control an extension.

## Limitations and next task

URL syntax validation remains intentionally lightweight and should be expanded with extension-contract tests later. The next queue item is FG-005, the Avalonia shell/design-token milestone.
