# FG-162 — Windows UI/UX audit and macOS-inspired polish

Plan: preserve the existing Catppuccin/Geist identity and Windows native caption. Improve semantic foreground contrast in both themes, light-theme primary gradient readability and success/warning text; retain quiet rounded navigation, increase navigation targets to the specified 40 DIP minimum, reserve the focus border to prevent movement, and scroll long profile navigation while keeping Settings reachable.

Audit (source review):
| Before | After | Why |
| --- | --- | --- |
| Low-contrast tertiary captions and light status colors | WCAG AA foregrounds on their actual surfaces | Readable guidance and recovery/health warnings |
| Light CTA gradient has a pale lavender midpoint | Deeper blue midpoint and white label | Keep the blue/mauve identity with legible action text |
| 36 DIP navigation rows, focus adds a border | 40 DIP rows with a reserved transparent border | Larger targets and stable keyboard feedback |
| Profile navigation cannot scroll | Bounded scroll region above a pinned Settings footer | Reach every profile at minimum window height |

Acceptance: WCAG sRGB contrast regression tests cover text surfaces, status backgrounds and sampled enabled CTA gradients; navigation accessibility/source contract checks; formatting, Release build and Desktop tests pass; version 0.1.12 standalone installer is regenerated, payload hash checked and package/graphical smoke validated.

Security/recovery: UI-only changes; do not activate focus, install a service, modify policy, or hide strict/recovery warnings. No installed-app update is authorized by this task. Visual runtime verification depends on available desktop tooling; do not claim screenshots if unavailable.
