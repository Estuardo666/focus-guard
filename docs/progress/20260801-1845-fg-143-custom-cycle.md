## UX implications

Custom editing remains in the inactive Focus surface and uses localized
English/Spanish labels, bounded numeric controls, and automation names. Strict
cycle review now exposes the exact service-returned phase boundaries in local
time before activation. The screen still keeps the existing Dark Zen hierarchy.

## Security implications

Break exceptions are created as Allow-only rules and are sent only through the
existing prepared-cycle IPC request. Desktop does not advance phases, extend
breaks, or enforce rules. Strict activation still requires the one-time recovery
credential and exact phrase, and cancellation discards the pending preparation
identifier locally.

## Limitations

- Statistics storage, retention, and the Activity dashboard have not started;
  they remain downstream of the cycle-history prerequisite.
