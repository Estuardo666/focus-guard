# FG-139 — domain and specification

## 1. Summary

Implemented the platform-independent Pomodoro domain slice. Focus cycle
configuration is validated against the product limits, and a deterministic
builder produces immutable UTC phase boundaries for cycle-count and
total-duration sessions. Simple timer sessions remain on the existing single
interval path.

## 5. UX implications

The future preview can list every phase, the exact end time, and whether its
last phase is partial. No final UI or timer behavior changed in this slice.

## 6. Security implications

The builder only creates data and cannot relax enforcement, skip a break, or
terminate a session. The service must later authenticate and integrity-protect
the serialized plan before applying break exceptions.

## 7. Limitations

Presets, persistence, IPC preparation/activation, service phase authority,
break exceptions, restart recovery, enforcement, and Desktop UI are deferred
to FG-140 through FG-145. The current domain plan intentionally does not use
`TimeProvider` or platform dependencies; callers supply the UTC start.
