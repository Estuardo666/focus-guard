# FG-003 checkpoint

## Summary

Added a pure application rule matcher for normalized exact paths, folder boundaries, file names, and caller-supplied SHA-256 snapshots.

## Acceptance evidence

- No process enumeration, opening, termination, or platform APIs are used.
- Windows path separators and case are normalized for path comparisons.
- Folder matching does not treat sibling prefixes as children.
- Release build completed with zero warnings/errors and 15/15 tests passed.

## Security, UX, and recovery implications

The matcher is safe to run against simulated snapshots and does not block applications. Protected-process exclusions and real process actions remain intentionally deferred.

## Limitations and next task

Hash format validation and process-source integration are future work. Next: FG-004 URL rule matching and precedence.
