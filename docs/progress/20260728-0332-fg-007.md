# FG-007 checkpoint

## Summary

Added a separate active-session Focus view backed by an injectable `TimeProvider` and the domain session expiration rules.

## Acceptance evidence

- Remaining time is rendered as an accessible text value and updates through `Refresh()`.
- Exact end time is displayed in local time while the model stores UTC.
- Mode, profile, rule counts, health, and recent block count are visible in the active view.
- The normal-mode stop action is explicit and simulator-only.
- Fake-clock tests verify countdown formatting and expiration at the exact end time without sleeping.
- Release build completed with zero warnings/errors.
- Domain tests: 18/18 passed. Desktop tests: 4/4 passed.

## UX implications

The timer is the visual focal point, with exact end time and health kept adjacent as text. Expiration explains that restrictions are released in the simulator; no false enforcement claim is made.

## Security and recovery implications

The view never terminates processes, controls browsers, persists strict state, or invokes elevation. Expiration delegates to the immutable domain session behavior.

## Limitations and next task

This view is not yet connected to service IPC or live navigation, and `RecentBlockCount` remains mock data. Next: FG-008 profile editor application-rule screen.
