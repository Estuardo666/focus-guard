## Ensayo elevado

El usuario pidió elevar la consola. Se usó el flujo normal de Windows `RunAs`; el hijo PowerShell confirmó `AdminToken=true` para Stuart en sesión 1. No se automatizó ningún diálogo UAC.

`scripts/invoke-installer-rollback-drill.ps1 -PackageDirectory artifacts/fg333-output -Execute -OwnerPresent` ejecutó la actualización de prueba. El instalador llegó al fallo esperado `Injected rollback verification failure after binary replacement.` y restauró el estado anterior. Resultado del drill: `TreeDifferences=0`, Service `Running`, `DesktopStillRunning=false`, `AgentRunning=true`; el proceso elevado terminó con exit 0.
