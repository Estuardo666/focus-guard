# FG-152 installer 0.1.2 plan

## Plan

1. Run installer contract tests against the current scripts.
2. Publish the production Desktop, Service, ProcessAgent, NativeMessaging host,
   Recovery utility, browser extension, and graphical setup as version 0.1.2.
3. Verify the standalone executable's embedded payload and graphical smoke path.
4. Record artifact size, SHA-256, test results, and installation instructions.

## Security, UX, and recovery implications

- Security: packaging must preserve production IPC names, signed-policy integrity,
  finite expiration, fail-open channel loss, and recovery tooling.
- UX: the packaged Desktop must contain scroll retention and the localized `No rules`
  state from FG-151.
- Recovery: this task only builds artifacts. It does not elevate, install, restart,
  or alter the currently running FocusGuard instance.

## Acceptance criteria

- Installer contract tests pass.
- `FocusGuard-0.1.2-Setup.exe` is generated as a standalone file.
- Embedded package self-test and non-installing graphical smoke test pass.
- SHA-256 and exact artifact path are reported.
