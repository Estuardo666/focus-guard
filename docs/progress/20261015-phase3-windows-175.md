# Fase 3: ajustes portátiles y excepciones locales en Windows .175

## Resumen y archivos

Se integraron dos requisitos que la auditoría encontró preparados solo en el núcleo: exportación/importación portátil y overrides locales por campo. Implementación detallada en `20261015-phase3-portable-settings.md` y `20261015-phase3-local-overrides-core.md`. Cambios abarcan Core/Windows Sync, almacenamiento DesktopSettings, HostAccountService y diálogos nativos, bridge, AccountPanel/cliente/locales EN/ES, pruebas correspondientes y versiones UI/extensión `.175`.

## Comportamiento y seguridad

- Exportación voluntaria JSON con solo tema/idioma/duración; importación de hasta 8 KiB, preview nativo, selección y confirmación. Sin cuenta aplica los campos bajo lease de preferencias; con consentimiento utiliza el outbox/worker E2EE. Un baseline obsoleto o preferencias corruptas se rechazan conservando datos.
- Excepciones locales en DPAPI por cuenta/generación/dispositivo. Cambiar o quitar una excepción no habilita consentimiento ni publica; quitarla muestra el último valor global. Ediciones/importaciones respetan la elección por campo. Reset y tombstones conservan las excepciones; ni rutas ni políticas se sincronizan.
- La confirmación nativa revalida revisión, excepciones previas y valores efectivos; cancelar no escribe. El bridge no acepta rutas o valores de archivo/override arbitrarios.
- Compatibilidad de actualización: outboxes antiguos se leen con excepciones vacías. Después del siguiente guardado `.175`, el lector estricto `.174` rechaza el campo nuevo y preserva el archivo. Recuperar con `.175`; no eliminar datos ni debilitar validación para un downgrade.
